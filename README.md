# Portafolio Profesional — Lorena Guadalupe Mendoza Pérez

Sitio web personal y portafolio profesional de **Lorena Guadalupe Mendoza Pérez**, Licenciada en Ciencias de la Comunicación (UNAM) y Analista de Información.

## 🌟 Características
- **Diseño Editorial & Ejecutivo**: Estilo responsivo con soporte para Modo Oscuro y Claro.
- **Línea de Tiempo Interactiva**: Filtros por área de desempeño institucional y operativo.
- **Catálogo de Certificaciones con Búsqueda en Vivo**: Más de 25 cursos y diplomados acreditados por FGR, UNAM, El Colegio de México, entre otros.
- **Visor Integrado de Currículum Vitae**: Visualización y descarga directa en PDF.
- **Vías de Contacto Directo**: Enlace a WhatsApp, copia rápida de correo institucional y formulario.

## 🚀 Despliegue en GitHub Pages
Este proyecto está optimizado con HTML5, CSS3 y JavaScript vanilla para funcionar de inmediato sin dependencias ni compilación.

Para activarlo en GitHub Pages:
1. Ve a **Settings** > **Pages** en tu repositorio de GitHub.
2. En **Build and deployment** > **Branch**, selecciona `main` y la carpeta `/ (root)`.
3. Haz clic en **Save**. ¡Tu sitio estará en línea en un par de minutos!
